# Shopping Trends Data Analysis Project

## 📊 Project Overview

This project analyzes shopping trends data using Python for exploratory data analysis (EDA) and Power BI for interactive dashboard creation. The analysis provides insights into customer shopping behavior, purchase patterns, and demographic trends.

## 🎯 Project Goals

- Perform comprehensive exploratory data analysis on shopping trends data
- Create interactive Power BI dashboards for data visualization
- Identify key insights and patterns in customer shopping behavior
- Provide actionable recommendations based on data findings
